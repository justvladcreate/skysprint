# **What is this?**

This repo is about a game environment for presenting Genetic Evolution usecase for game developers as a **[course paper](https://github.com/justvladcreate/Course-paper-25-26)** project.

Based on mobile game [retry](https://zeros-unity-ports.itch.io/retry-again) and adapted with pygame to use, test and create virtual agents.

Feel free to copy over the repo and try out presets of trained models.

You can also train your own agents.
